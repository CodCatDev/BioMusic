## About
BioMusic is a userbot that displays your current track in the address field of your Telegram profile. It retrieves music from [Last.fm](http://www.last.fm/)

## Installation

### Requirements

- [PyroFork](https://github.com/Mayuri-Chan/pyrofork)
- [Last.fm account](https://www.last.fm/join)
- [Last.fm API key](https://www.last.fm/api/account/create)

### Usage

1. Clone repo `git clone https://github.com/CodCatDev/BioMusic`
2. Set `API_ID` and `API_HASH` in config.py
3. Set `LFM_API_KEY` and `LFM_USER` in config.py
4. Run `python3 music.py`
